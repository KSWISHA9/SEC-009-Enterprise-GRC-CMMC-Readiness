## Method and Status Definitions

v1.0 review: selected mappings remain evidence-limited; no row status or risk closure is upgraded by finalizing the portfolio. The [fictional vendor review](../Vendor-Assessment/Atlantic-Defense-Cloud-Services-Assessment.md) uses Unverified for missing supplier evidence, not an official CMMC finding. No vendor safeguards are credited to this matrix or the SSP.

Each row has a framework identifier, a locally scoped assessment objective, an existing safeguard, an evidence reference, a status and a gap/remediation. Objectives below are paraphrased review questions, not a replacement for official assessment objectives. See [Evidence Traceability](Evidence-Traceability.md) for exact filenames, observed command outputs, provenance and limitations. Commands are recorded from evidence; none was executed on a VM by this assessment.

| Local status | Meaning |
| --- | --- |
| Met | Sufficient evidence covers the stated scope and applicable objectives; not awarded merely for a successful narrow test |
| Partially Demonstrated | Some relevant safeguards or results are evidenced, but objective coverage, deployment scope or operational assurance remains incomplete |
| Not Met | Evidence establishes failure against an applicable defined objective; missing evidence alone is not automatically failure |
| Not Assessed | No adequate assessment of the objective was performed; implementation is not presumed absent |

No row is rated Met: the current captures do not establish full control/requirement coverage. Configuration remediation and individual successful tests remain valid results even when their broader control is Partially Demonstrated.

These four statuses are **local readiness labels**, not official CMMC findings. CMMC Level 2 assessment terminology uses MET, NOT MET and NOT APPLICABLE, based on assessment-objective evaluation. Partially Demonstrated is not an official partial-credit finding, and Not Assessed is not an exemption. No official CMMC outcome, aggregate score or conditional eligibility is issued. See the [DoD Level 2 Assessment Guide](https://dodcio.defense.gov/Portals/0/Documents/CMMC/AssessmentGuideL2v2.pdf) and [32 CFR Part 170](https://www.govinfo.gov/link/cfr/32/170?link-type=pdf&year=mostrecent).
